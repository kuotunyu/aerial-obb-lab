# Browser-Native UI Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Subagents and extra threads are prohibited for this project.

**Goal:** Replace every maintained Gradio demo path with one distinctive, readable, space-efficient browser-native ONNX Runtime Web workbench.

**Architecture:** Preserve the existing framework-free `obb.js` geometry contract and browser-only ONNX Runtime Web WASM execution. Rename the maintained app to `demo/web/`, rebuild its semantic HTML/CSS presentation, keep inference in `app.js`, and make the existing synthetic Playwright smoke the executable UI contract. Remove the duplicate Python UI surface and update every release gate, document, dependency, and evidence record to describe the single browser app.

**Tech Stack:** Semantic HTML5, CSS, vanilla JavaScript, Canvas 2D, ONNX Runtime Web 1.20.1 WASM, Python 3.11 release scripts, pytest, Node.js geometry parity runner, Playwright Chromium.

## Global Constraints

- Work only on `portfolio/obb-v1.0-release-hardening`; do not rewrite, amend, squash, or rebase.
- Author and committer must be `kuotunyu <61350295+kuotunyu@users.noreply.github.com>` with no `Co-authored-by` trailer.
- Use exact-path staging; never use `git add -A`.
- Keep `notes.private.md`, interview material, `.env`, weights, datasets, screenshots outside the approved committed asset, and runtime artifacts ignored and unstaged.
- Set `CUDA_VISIBLE_DEVICES=-1`; do not train, run full validation, build TensorRT, or start GPU inference.
- Do not add or download a model, dataset, benchmark, hosted backend, or restricted image.
- The browser accepts only a user-supplied compatible ONNX file and processes model bytes and image pixels locally.
- The browser UI does not represent fine-tuned `yolo26m-obb` accuracy or the recorded T4 latency.
- Do not create or modify a remote, PR, tag, Release, GitHub Pages site, Hugging Face Space, or model repository during implementation.
- Preserve the `images [1,3,1024,1024]` input and `output0 [1,N,7]` end-to-end output contract.
- Use Traditional Chinese (`zh-TW`) for primary UI copy while retaining established technical terms in English.
- Use an 18px base font, 17–18px labels/controls, a 38–42px desktop title, 44px minimum controls, a roughly 34/66 desktop grid, a 900px responsive breakpoint, and a content width near 1600px.
- Avoid gradients, glass effects, neon, decorative animation, nested cards, and large empty hero sections.

function setStatus(message, kind = "neutral") {

function renderSummary(dets, elapsedMs = null) {
  summaryCount.textContent = String(dets.length);
  summaryTop.textContent = dets.length
    ? Math.max(...dets.map((d) => d.conf)).toFixed(3)

  runtimeValue.textContent = elapsedMs === null ? "—" : `${Math.round(elapsedMs)} ms`;
